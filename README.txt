COMO USAR
1. Abra index.html no navegador.
2. Os projetos são cadastrados no início do script.js.
3. Os links apontam para os repositórios públicos informados.
4. Troque o WhatsApp de demonstração no index.html pelo número comercial real.
5. Publique no GitHub Pages, Netlify ou outro serviço de hospedagem estática.

OBSERVAÇÃO
As descrições foram escritas de forma profissional e conservadora a partir dos nomes dos projetos fornecidos. Antes de publicar como portfólio definitivo, revise qualquer descrição que queira tornar mais específica.
